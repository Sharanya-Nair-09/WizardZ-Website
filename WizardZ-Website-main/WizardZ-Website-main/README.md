# WizardZ-Website
A simple design website using HTML | CSS | JavaScript | GSAP
A modern, animated landing page inspired by the **Positivus** digital marketing website design.

This project focuses on clean layout structure, bold typography, strong UI elements, and smooth animations using **GSAP**.

---

## Overview

This website includes:

* Responsive Navigation Bar
* Hero Section with CTA
* Services Section (2x2 Card Layout)
* About Section
* Process Section
* Testimonial Section
* Call-To-Action Section
* Footer

The design emphasizes:

* Bold layouts
* Thick borders
* Heavy drop shadows
* Rounded corners
* Bright green accent color (#9AE975)

---

## Built With

* **HTML5**
* **CSS3**
* **JavaScript**
* **GSAP (GreenSock Animation Platform)**

---

## Design Features

* Clean 2-column hero layout
* 2x2 service card grid
* Bold typography and spacing
* High-contrast black borders
* Elevated shadow effect
* Smooth entrance animations using GSAP

---

## Animations

Implemented using **GSAP**:

* Navbar fade + slide-in
* Hero text stagger animation
* Card entrance animation
* Scroll-triggered effects
