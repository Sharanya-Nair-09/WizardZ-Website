# 🎨 Animated Design Website (Positivus Inspired)

A modern, animated landing page built using **HTML, CSS, JavaScript, and GSAP**, inspired by the *Positivus digital marketing website design*.

This project focuses on **clean layout structure, bold typography, strong UI elements, and smooth animations**.

---

## 🚀 Overview

This website includes:

- Responsive Navigation Bar  
- Hero Section with Call-To-Action  
- Services Section (2x2 Card Layout)  
- About Section  
- Process Section  
- Testimonial Section  
- Call-To-Action Section  
- Footer  

---

## 🎯 Design Highlights

- Bold layouts  
- Thick borders  
- Heavy drop shadows  
- Rounded corners  
- Bright green accent color `#9AE975`  

---

## 🛠️ Built With

- **HTML5**  
- **CSS3**  
- **JavaScript**  
- **GSAP (GreenSock Animation Platform)**  

---

## ✨ Design Features

- Clean **2-column hero layout**  
- Structured **2x2 service card grid**  
- Bold typography with strong spacing  
- High-contrast black borders  
- Elevated shadow effects  
- Smooth and modern UI feel  

---

## 🎬 Animations

Implemented using **GSAP**:

- Navbar **fade + slide-in**  
- Hero text **stagger animation**  
- Service cards **entrance animations**  
- Scroll-triggered effects
